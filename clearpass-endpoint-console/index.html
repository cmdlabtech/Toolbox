Before your first run This page talks to the CPPM REST API straight from your browser. Two things need to already be true: the browser trusts the ClearPass certificate (open https://your-cppm/api-docs once and accept it), and CPPM sends CORS headers back for this page's origin. If token requests succeed but everything after fails with a vague network error, that's almost always CORS — front CPPM with a small reverse proxy and point API base override below at it.

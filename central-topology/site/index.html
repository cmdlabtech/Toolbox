Central credentials

Credentials stay in this browser. They are sent only in request headers to HPE GreenLake and new Central (through a stateless pass-through that stores and logs nothing). Without credentials the page shows mock data.

Sign-in method

Use a personal API client from HPE GreenLake (Manage Workspace > Personal API clients). Enter the secret once: it keeps working for every new token, so you never need to reset it or paste tokens. Leave Workspace ID empty if the client's service is your new Central instance. If its service is HPE GreenLake platform, add the Workspace ID shown under Manage Workspace.

A pasted token stops working when it expires (15 minutes for a GreenLake platform client, 2 hours for a new Central client) and you have to paste a new one. Sign in with Client ID + secret instead and this page renews the token for you.
